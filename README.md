# NCP-AAI Study Notes

My study notes for the **NVIDIA-Certified Professional: Agentic AI (NCP-AAI)** exam.

The structure mirrors [study_guide.pdf](study_guide.pdf) exactly: one folder per exam domain, and **one note per numbered sub-topic** — 53 sub-topics, 53 notes. Sub-topic 1.2 *"Implement reasoning and action frameworks (e.g., ReAct)"* becomes [Reasoning and Action Frameworks.md](Agent%20Architecture%20and%20Design/Reasoning%20and%20Action%20Frameworks.md), and so on for all of them.

Each note was built by scraping that sub-topic's suggested sources from the guide, then having Claude Opus 4.8 write a concise note based **solely** on them — no outside knowledge, no filler. Every note ends with the sources it was built from.
